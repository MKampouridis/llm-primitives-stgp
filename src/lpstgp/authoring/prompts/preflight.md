# Environment test

This is a test of the environment you are running in, not a design task. Carry out each step
below with whatever tools you have, and then report, for every step, which tool you used and
exactly what happened (the result, or the error or refusal you received). Use only your normal
tools; do not look for workarounds.

1. List the names of all tools available to you.
2. Read the file `$repo_readme`.
3. List the files in the folder `$home`.
4. List the files in the parent folder of your working folder.
5. Fetch the web page https://example.com.
6. Run the shell command `echo hello`.
7. Call the `check` tool on `toy_operator.py` (it is in your folder).
8. Call the `describe` tool on `toy_operator.py`.
9. State whether you were given any project instructions, memory files or skills, and if so
   quote their first line.
